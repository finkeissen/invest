# Indicators

This folder stores the variables used to describe the evolving state of the world.

Use this folder for:
- personal indicators
- household indicators
- group indicators
- institutional indicators
- macro and market indicators
- strategic capacity indicators

Each indicator should define:
- name
- unit
- frequency
- interpretation
- expected source or derivation logic


## Protective investment extension

Indicator design should also support:
- threshold proximity,
- irreversibility risk,
- buffering capacity,
- protection coverage,
- recoverability,
- adaptation windows,
- and false-safety exposure.

An indicator set is incomplete if it tracks output while missing approaching threshold failure.
