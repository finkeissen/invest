# Universe

This folder defines the coverage boundary of the system.

Use this folder for:
- countries
- blocs
- regions
- sectors
- life domains
- collective domains
- inclusion and exclusion rules

Questions this folder should answer:
- Which entities are in scope?
- At what level are they modeled?
- Which life domains are included?
- Where are the boundaries of the simulated world?


## Protective investment extension

Universe definition should not only ask what is in scope for gain-seeking. It should also ask what is in scope for protection analysis:
- which risks and loss channels count,
- whose thresholds matter,
- which external supports are assumed,
- and which omitted actors or systems could make the protection story misleading.
