# Persons

This folder defines person-level starting conditions, person types, and person-relevant constraints.

Use it when the repository needs to reason about investment at the level of actual human beings rather than only institutions or markets.

Typical contents may include:
- person archetypes
- life-stage distinctions
- baseline capacities
- vulnerability classes
- person-level gain dimensions


## Protective investment extension

Person-level files should also include:
- defended life conditions,
- vulnerability to threshold events,
- realistic protection options,
- recoverability under major setbacks,
- and life-stage shifts in what protection means.

This keeps person-level modeling from collapsing into income-only or asset-only reasoning.
