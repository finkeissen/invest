# Snapshots

This folder stores dated input states for reproducible research and simulation runs.

Use this folder for:
- frozen input bundles
- dated parameter baselines
- reproducibility checkpoints
- run-specific input manifests


## Protective investment extension

Snapshots should preserve not only state but also protection-relevant state:
- current protection gaps,
- threshold exposures,
- buffering resources,
- transfer mechanisms in force,
- recovery conditions,
- and known false-safety risks.
