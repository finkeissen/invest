# Groups

This folder defines collective forms that matter for investment analysis.

Use it for households, communities, firms, churches, institutions, alliances, and other groups whose gains and losses cannot be reduced to a single person-model.

Each group description should clarify:
- membership and boundaries
- decision structure
- resource base
- distribution of gains and losses
- coordination constraints


## Protective investment extension

Group descriptions should additionally clarify:
- what collective conditions must remain intact,
- which members bear concentrated downside under stress,
- what repair and recovery obligations the group carries,
- and whether apparent group stability depends on hidden sacrifices by identifiable people.
