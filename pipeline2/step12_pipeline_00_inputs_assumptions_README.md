# Assumptions

This folder makes explicit what the system currently assumes before formal modeling begins.

Use this folder for:
- baseline world assumptions
- simplifications
- exclusions
- priors
- scenario premises
- unresolved uncertainties
- practical and ethical guardrails
- threshold assumptions about what must remain intact for a good life to remain possible
- assumptions about protection, buffering, recoverability, and systemic support under stress
- explicit uncertainty about tail risks, low-frequency high-impact events, and hidden protection gaps
