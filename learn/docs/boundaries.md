# Boundaries

Things this framework deliberately does not do, and why.

This is a non-normative document.
It exists so that intent is not inferred from silence elsewhere.

---

## The framework does not decide what to learn

A learner's goals enter from outside.

The framework does not generate goals, recommend goals, prioritise
goals against one another, or judge whether a goal is worth pursuing.
Where a system appears to do these things, it is because it embeds
an authority that is **not** part of this framework.

This is structural, not modesty.
Allowing the framework to derive goals would dissolve the boundary
between framework and authority, and make every contract negotiable
under sufficient pressure.

---

## The framework does not assess the learner

Dimension shift levels are observed, not assigned.

The framework records what evidence has established.
It does not infer character, capacity, or potential from the record.

The same record that says "level 2 observed on concept X" does not
say "the learner is level 2".
It says: at the time of observation, against this concept, this is
what was demonstrable.

The distinction is not pedantic.
It is what keeps the record from becoming a verdict.

---

## The framework does not predict outcomes

The framework's artifacts can support prediction by external systems.
The framework itself does not predict.

It does not declare:
- this learner will pass exam X,
- this learner is on track for outcome Y,
- this intervention will succeed.

Such claims belong to systems that take responsibility for them.
The framework provides input; it does not assume the output.

---

## The framework does not optimise

There is no objective function.
There is no "best" intervention, "best" path, "best" learner state.

The framework supports decisions that an external authority is
making (a learner, a teacher, an institution).
It clarifies the state and the options.
It does not select.

A system layered on top may optimise.
That system declares its own objective.
The framework records what it does, and remains silent on whether
the choice was correct.

---

## The framework does not aggregate identities

A learner's record across goal contexts is structurally separable.

The framework does not produce a single profile, score, or ranking
of a learner across their entire life.
It refuses to do so.

Where such an aggregate is needed, it is constructed elsewhere,
under explicit authority, with explicit purpose.
The framework provides the inputs, and records that they were
provided. The aggregate is not the framework's claim.

---

## The framework does not survive misuse silently

If the framework's contracts are violated and the violation is
absorbed without STOP, the framework is no longer present in a
meaningful sense.

The combinations of obligations and STOP conditions across the
contracts exist precisely so that misuse cannot be quiet.
A system claiming framework conformance while ignoring STOP is
not in conformance, regardless of its outputs.

This is the framework's only enforcement mechanism, and it is
deliberately structural rather than legal.
